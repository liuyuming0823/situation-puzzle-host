# 海龟汤谜题设计模板

> 复制本文件填充内容。每一局都必须先在内部填满以下字段，再向用户展示谜面。
> 难度决定关键事实条数：简单 8 条、普通 10 条、困难 12 条。

```
谜面：[一句话异常表象，足够吊胃口，不含真相]
谜底：[一句话完整真相]
难度：[简单 / 普通 / 困难]
主题：[日常 / 悬疑 / 职场 / 校园]

关键事实（按维度覆盖，编号 K1..Kn）：
  K1 [人物] 主角身份 / 与他人的关系
  K2 [时间] 事件发生的时机
  K3 [地点] 场景
  K4 [表象] 用户看到的异常是什么
  K5 [成因] 异常为什么发生
  K6 [转折] 关键误会 / 反转点
  K7 [真相] 完整真相的核心
  K8 [收尾] 结局
  K9 ...（困难补足到 12 条）
  K10 ...
  K11 ...
  K12 ...

可问方向提示（仅内部备用，不主动展示）：
  - 用户最可能从哪个表象切入
  - 哪条关键事实最容易漏问（复盘时重点看）
```

## 出题约束

1. 谜面可以反常，但谜底必须能自圆其说，所有关键事实彼此不矛盾
2. 关键事实必须「可证伪」——能被「是 / 不是」回答，不写「也许」「可能」类模糊句
3. 不做真实未结案件、不写犯罪手法教学、不写自残方法
4. 同一局不得出现两套真相；用户猜的方向再合理，只要不是本局谜底，就答「不是」

## 难度参考

- 简单：表象与真相落差小，8 条事实，提示 3 次足够
- 普通：有一处反转，10 条事实
- 困难：多重误会或时间线交错，12 条事实，建议用户多轮推进
