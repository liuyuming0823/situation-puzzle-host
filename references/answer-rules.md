# 海龟汤四答判定细则与关键事实清单模板

本文件是主持判定与出题的硬性知识，按需加载。一切回答以「开局锁定的关键事实」为唯一准绳，不得临时发明。

## 一、关键事实清单模板

开局第一步必须内部写出 8~12 条关键事实，覆盖「人物 / 时间 / 地点 / 异常表象的成因 / 转折 / 真相」六个维度。事实要可证伪（能回答「是」或「不是」），不要写模糊描述。

```
谜面：[呈现给用户的异常表象，一句话，足够吊胃口]
谜底：[完整真相，一句话讲清怎么回事]
难度：[简单/普通/困难]
关键事实（8~12 条，编号 K1..Kn）：
  K1 [人物] 主角身份/关系
  K2 [时间] 事件发生的时机
  K3 [地点] 场景
  K4 [表象] 用户看到的异常是什么
  K5 [成因] 异常为什么发生
  K6 [转折] 关键误会/反转点
  K7 [真相] 完整真相的核心
  K8 [收尾] 结局
  ... 按需补足到 8~12 条
```

示例（普通难度，日常）：

```
谜面：一个人走进餐厅，对服务员说「我点的菜还没上」，服务员看他一眼说「您没点过啊」，那人却淡定地坐下吃了顿免费的饭。
谜底：此人是餐厅老板，他用自己的员工权限「点」了一单记在店里账上，服务员不认识新来的老板。
K1 主角是这家餐厅的老板
K2 事件发生在他刚接手餐厅的第一天
K3 地点是餐厅大堂
K4 表象：陌生人声称点过菜却无订单记录
K5 成因：他用老板后台账号下了一单，不生成前厅点餐单
K6 转折：服务员不认识新老板，以为遇上加塞的
K7 真相：他吃的是自己店里的饭，账记在公司
K8 收尾：事后身份澄清，成为内部笑话
```

## 二、四类回答判定细则

回答前，把用户的问题拆成可被关键事实证伪的子命题，逐条比对，再合成最终回答。

### 1. 是
用户陈述的事实与某条关键事实（或由其必然推出的结论）完全一致。可直接答「是」。

### 2. 不是
用户陈述的事实与本局任何关键事实都不符。包括两种情况：
- **与真相矛盾**（如真实是意外，用户猜「谋杀」）→ 答「不是」。
- **是谜底之外的合理推测**（如真实是梦游，用户猜「装病」）——这条最容易错：只要不是本局真相，哪怕逻辑自洽、现实里可能发生，也答「不是」。**绝不因为「说得通」就认可，也绝不借机扩展设定解释为什么不是。**

### 3. 无关
用户的问题既不支持也不否定任何关键事实，属于本局设定之外的闲聊、情绪表达、或对本技能机制的询问（如「这题谁出的」）。答「无关」，不提供任何信息增量。

### 4. 部分正确
仅当用户的一句话里同时包含「成立的部分」和「不成立的部分」时才用。必须按以下格式，且不得超纲：
- 先说哪部分成立（引用具体子命题）
- 再说哪部分不成立
- **严禁**追加方向性提示（如「你方向接近了」「再往 XX 想想」）、严禁透露未问出的关键事实

反例（错误）：「部分正确，你猜到他身份特殊了，但再想想他和餐厅的关系。」——后半句泄题。
正例（正确）：「部分正确，他确实和餐厅有关，但他不是顾客。」

## 三、判定自检清单（每次回答前默念）

1. 我的回答能不能从关键事实里找到依据？找不到就只能是「不是」或「无关」。
2. 用户是不是在问谜底之外的合理推测？是 → 答「不是」，不解释。
3. 我用「部分正确」时有没有夹带新信息或方向词？有 → 删掉。
4. 我有没有为了圆故事改写任何一条关键事实？有 → 立即停止，回到原事实。

## 四、内容安全红线

命中以下任何一项，不得主持该情境，改为安全虚构并重开：
- 自残 / 自杀方法的具体描述
- 犯罪手法的可操作教学（如如何下毒、如何入侵）
- 指向真实未结案件或真实人物
- 色情、极端暴力渲染

处理方式：不展开，直接说「这个方向不合适，我换一个安全的谜题」，然后走重开流程。
